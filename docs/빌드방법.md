# ParticleTracker 빌드 방법

소스 코드에서 macOS 앱(`ParticleTracker.app`)과 배포용 DMG를 만드는 방법입니다.
설치만 하려면 [설치방법.md](설치방법.md)를 보세요.

## 필요한 것
- macOS (빌드한 Mac과 같은 CPU 종류용 앱이 만들어집니다: Apple Silicon Mac → arm64 앱)
- **Python 3.12** (3.10 이상이면 동작하지만 빌드는 3.12 기준). macOS 기본 `python3`(3.9)은 너무 오래되었습니다.
  - 권장: [uv](https://docs.astral.sh/uv/)로 설치
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    uv python install 3.12
    ```
    uv로 설치한 `python3.12`는 `~/.local/bin`에 있으므로 빌드할 때 `PATH`에 넣어 줍니다(아래 명령 참고).
- 인터넷 (처음 한 번 패키지 설치)
- Xcode Command Line Tools (`xcode-select --install`) — `hdiutil`, `codesign`, `ditto` 사용

## 1. 저장소 받기
```bash
git clone https://github.com/windowrainYOON/particle-tracking.git
cd particle-tracking
```

## 2. 앱 빌드 (+ /Applications 설치)
```bash
PATH="$HOME/.local/bin:$PATH" ./build_mac_app.sh
```
하는 일:
1. `.venv`가 없으면 `python3.12 -m venv .venv`로 만들고 `requirements.txt` 설치
2. PyInstaller 설치 후 `launcher.py`를 `dist/ParticleTracker.app`으로 빌드
   (아이콘 `assets/ParticleTracker.icns`, scikit-image·imageio-ffmpeg·matplotlib 데이터 포함)
3. `/Applications/ParticleTracker.app`으로 복사해 설치
   - 앱이 실행 중이면 설치를 건너뜁니다. 앱을 끄고 다시 실행하세요.
   - 설치하지 않으려면 `./build_mac_app.sh --no-install`

처음 빌드는 패키지 설치 때문에 수 분, 이후에는 1–2분 걸립니다. 결과 앱은 약 300 MB입니다.

## 3. 배포용 DMG 만들기
```bash
PATH="$HOME/.local/bin:$PATH" ./build_dmg.sh                  # 앱 새로 빌드 → dist/ParticleTracker-<버전>.dmg
PATH="$HOME/.local/bin:$PATH" ./build_dmg.sh --skip-build     # 이미 빌드한 dist/ParticleTracker.app 사용
PATH="$HOME/.local/bin:$PATH" ./build_dmg.sh --skip-build --out ~/Desktop   # 바탕화면에 저장
```
DMG 안에는 `ParticleTracker.app`, `Applications` 바로가기(끌어다 놓아 설치), `문서` 폴더(사용·설치·빌드 문서, README, 변경 이력)가 들어갑니다.
버전은 `ptracker/__init__.py`의 `__version__`에서 가져옵니다. **`*.dmg`는 `.gitignore`에 있어 커밋되지 않습니다.**

### 서명과 공증
빌드한 앱은 ad-hoc 서명만 되어 있습니다. 빌드한 Mac에서는 바로 열리지만, DMG를 다른 Mac에 보내면
처음 한 번 보안 경고가 뜹니다([설치방법.md](설치방법.md) 참고). 경고 없이 배포하려면 Apple Developer ID 인증서로
`codesign --deep --options runtime` 서명 후 `xcrun notarytool submit … --wait`, `xcrun stapler staple`로 공증해야 합니다.

## 4. 테스트
```bash
./.venv/bin/python tests/test_pipeline.py      # 합성 데이터로 전체 흐름 확인
```

## 5. 버전 올리기와 아이콘
- 새 버전: `ptracker/__init__.py`의 `__version__`을 올리고 `CHANGELOG.md`에 변경 내용 추가 → 앱·DMG 다시 빌드
- 아이콘 다시 만들기: `./.venv/bin/python tools/make_icon.py` → `assets/ParticleTracker.icns`

## 6. 빌드가 안 될 때
| 증상 | 해결 |
|---|---|
| `python3.12: command not found` | `PATH="$HOME/.local/bin:$PATH"`를 앞에 붙였는지, `uv python install 3.12`를 했는지 확인 |
| 패키지 버전 충돌·이상한 오류 | `rm -rf .venv build dist` 후 다시 빌드 |
| "설치를 건너뜁니다" | `/Applications`의 ParticleTracker를 종료하고 다시 실행 |
| `hdiutil: create failed - Resource busy` | 같은 이름의 DMG가 마운트되어 있음. Finder에서 꺼낸 뒤 다시 실행 |
| 빌드한 앱이 바로 꺼짐 | 터미널에서 `dist/ParticleTracker.app/Contents/MacOS/ParticleTracker`를 직접 실행해 오류 메시지 확인 |
