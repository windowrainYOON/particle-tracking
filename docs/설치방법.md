# ParticleTracker 설치 방법

## 필요한 환경
- **macOS 13 이상, Apple Silicon(M1/M2/M3/M4) Mac**
  - 배포용 DMG의 앱은 Apple Silicon용으로 빌드됩니다. Intel Mac에서는 [빌드방법.md](빌드방법.md)대로 그 Mac에서 직접 빌드하거나 소스로 실행하세요.
- 메모리 16 GB 이상 권장 (데이터셋 하나 처리에 약 3–4 GB)
- 디스크: 앱 약 300 MB, 결과는 데이터셋당 수백 MB–수 GB (영상 포함)
- Python은 **필요 없습니다** (앱 안에 모두 들어 있음).

---

## 1. DMG로 설치하기 (권장)

1. `ParticleTracker-<버전>.dmg`를 더블클릭해 엽니다.
2. 열린 창에서 **ParticleTracker** 아이콘을 옆의 **Applications** 폴더로 끌어다 놓습니다.
   - 이전 버전이 있으면 "대치"를 누르세요. 설정은 홈 폴더에 따로 저장되므로 지워지지 않습니다.
3. DMG 창을 닫고, Finder 사이드바에서 디스크 이미지 옆 ⏏ 버튼으로 꺼냅니다.
4. Launchpad 또는 `응용 프로그램` 폴더에서 ParticleTracker를 엽니다. 자주 쓰면 Dock에 끌어다 두세요.

DMG 안의 `문서` 폴더에 사용 방법·설치 방법·빌드 방법 문서가 함께 들어 있습니다.

### 처음 열 때 보안 경고가 뜨면
이 앱은 Apple 개발자 인증서로 서명·공증되지 않았기 때문에, 다른 Mac에서 내려받거나 복사해 온 경우
"Apple은 'ParticleTracker'에 악성 코드가 없음을 확인할 수 없습니다" 같은 경고가 뜰 수 있습니다.

**방법 A (macOS 15 Sequoia 이상)**
1. 경고 창에서 **완료**를 누릅니다.
2. **시스템 설정 > 개인정보 보호 및 보안**으로 갑니다.
3. 아래쪽 "보안" 항목의 *'ParticleTracker'이(가) 차단되었습니다* 옆 **그래도 열기**를 누르고 암호를 입력합니다.
4. 다시 열면 **열기**를 누릅니다. 이후로는 바로 열립니다.

**방법 B (macOS 14 이하)**
Finder에서 앱을 **우클릭(또는 Control+클릭) → 열기 → 열기**.

**방법 C (터미널)**
```bash
xattr -dr com.apple.quarantine /Applications/ParticleTracker.app
```

이 Mac에서 직접 빌드한 앱은 경고 없이 바로 열립니다.

## 2. 소스에서 바로 실행하기 (개발·수정용)

앱으로 만들지 않고 Python으로 실행합니다. 코드를 고치면서 쓸 때 편합니다.

1. Python **3.10 이상**을 설치합니다 (예: <https://www.python.org/downloads/macos/> 또는 `uv python install 3.12`).
2. 저장소를 받습니다.
   ```bash
   git clone https://github.com/windowrainYOON/particle-tracking.git
   ```
3. 폴더 안의 **`run_mac.command`를 더블클릭**합니다.
   - 처음 한 번은 `.venv` 가상환경을 만들고 패키지를 설치합니다(인터넷 필요, 수 분).
   - 터미널에서 직접 하려면:
     ```bash
     cd particle-tracking
     python3.12 -m venv .venv
     ./.venv/bin/pip install -r requirements.txt
     ./.venv/bin/python -m ptracker
     ```

---

## 3. 업데이트와 삭제

- **업데이트**: 새 DMG로 1번 과정을 반복해 덮어씁니다.
- **삭제**: `응용 프로그램`에서 ParticleTracker를 휴지통으로 옮깁니다.
  설정까지 지우려면 아래 파일·폴더도 지웁니다.
  - `~/.particletracker_last.yaml` (마지막 파라미터)
  - `~/.particletracker/` (학습된 연결 모델)
  - `~/Library/Preferences/com.particletracker.ParticleTracker.plist` (최근 폴더, 출력 폴더 등)

분석 결과 폴더는 앱을 지워도 그대로 남습니다.
