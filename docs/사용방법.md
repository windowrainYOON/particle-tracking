# ParticleTracker 사용 방법 (처음 쓰는 분을 위한 안내)

ParticleTracker는 **measure · reference · RI** 세 역할의 타임랩스(예: pHrodo · Cy5 · HT)에서 입자를 찾아 프레임마다 따라가고(트래킹),
입자별 **I(measure)/I(reference)** 비율이 시간에 따라 어떻게 변하는지 세포 안/밖으로 나눠 보여 주는 프로그램입니다.
Tomocube **raw TCF 파일을 바로** 넣고, 파일 안의 채널(CH0, CH1, RI …)을 각 역할에 직접 할당할 수 있습니다.

- 설치는 [설치방법.md](설치방법.md), 직접 빌드하는 방법은 [빌드방법.md](빌드방법.md)를 보세요.
- 알고리즘과 출력 파일의 자세한 설명은 저장소의 [README.md](../README.md)에 있습니다.

---

## 0. 한눈에 보는 순서

```
① 데이터 넣기 → ② (필요하면) 파라미터 조정 → ③ 실행 → ④ 결과 보기
                                             ↓
                     ⑤ 여러 데이터셋 통합 → ⑥ 특이 입자 찾기 → 크롭 영상
```

처음이라면 **파라미터를 건드리지 않고 기본값으로 데이터셋 하나를 끝까지 실행**해 보는 것을 권합니다.
기본값은 실제 데이터 4세트에서 맞춘 값입니다.

---

## 1. 준비할 데이터

한 데이터셋 = 같은 시야를 찍은 **세 가지 역할**의 타임랩스입니다.

| 역할 | 예 | 용도 |
|---|---|---|
| **measure** (B) | pHrodo | 측정 대상 형광. 비율의 분자 |
| **reference** (A) | Cy5 | 입자 검출(내부 대조). 비율의 분모 |
| **RI** | HT 굴절률 z-projection | 세포 영역·분열 판정, 입자 RI |

결과 그래프의 비율은 **I(measure)/I(reference)** 로 표시됩니다.

### 1-1. raw TCF 파일 (권장)
Tomocube가 저장한 `.TCF` 파일을 변환 없이 바로 넣을 수 있습니다. TCF 하나 = 데이터셋 하나입니다.
TCF 안에는 보통 다음 채널이 들어 있습니다.

| 채널 | 내용 |
|---|---|
| `CH0`, `CH1`, (`CH2`) | 형광 채널 (z-projection, 창에 들뜸/방출 파장이 함께 표시됨) |
| `RI` | 굴절률 z-projection (HT) |

TCF를 추가하면 **채널 할당 창**이 열리고, 각 채널을 어느 역할에 쓸지 직접 고릅니다 (3-1 참고).
예: `CH0 → measure (pHrodo)`, `CH1 → reference (Cy5)`, `RI → RI`.

- 외장 드라이브의 TCF도 그대로 쓸 수 있습니다. 분석 중에는 드라이브를 연결해 두세요.
- 여러 TCF를 한꺼번에 고르면 같은 할당이 모두에 적용됩니다. 할당한 채널이 없는 파일(예: 형광 없이 HT만 찍은 파일)은 건너뜁니다.
- 형광과 RI의 촬영 시각이 조금 달라도 reference 채널의 각 시점에 가장 가까운 프레임을 자동으로 맞춥니다.
- 프레임 간격은 TCF의 촬영 시각에서 읽어, 파라미터 값과 다르면 할당 창에서 바꿀지 물어봅니다.

### 1-2. tif 파일
기존처럼 채널별 tif 스택 3개(프레임 수가 같아야 함)도 쓸 수 있습니다.
파일명에 키워드가 있으면 역할이 자동으로 정해집니다.

| 역할 | 파일명에 들어 있어야 할 글자 (기본값) |
|---|---|
| measure | `pHrodo` |
| reference | `Cy5` |
| RI | `HT` |

파일명 예시 (키워드를 뺀 나머지가 같으면 한 세트로 묶입니다):

```
pHrodo_P01.tif   Cy5_P01.tif   HT_P01.tif    → 데이터셋 "P01"
pHrodo_P02.tif   Cy5_P02.tif   HT_P02.tif    → 데이터셋 "P02"
```

- 대소문자는 구분하지 않습니다.
- 파일명 규칙이 다르면 [2. 파라미터 > 채널·시간]에서 키워드를 바꾸거나, [수동 추가 (tif)]로 세 파일을 직접 고르세요.

### 1-3. 공통
- [2. 파라미터 > 채널·시간]의 **프레임 간격(분)**(기본 20분)이 실제 촬영 간격과 같은지 확인하세요. 그래프의 시간 축에 쓰입니다.
- iCloud Drive에만 있고 내려받지 않은 파일은 읽을 수 없습니다. Finder에서 먼저 내려받으세요.
- 메모리: 1464×1464 × 38프레임 데이터셋 하나에 약 3–4 GB가 필요합니다.

## 2. 프로그램 열기

## 3. [1. 데이터·실행] 탭: 데이터 넣고 실행하기

### 3-1. 데이터 추가
| 버튼 | 하는 일 |
|---|---|
| **TCF 파일 추가 (채널 할당)** | raw TCF를 하나 또는 여러 개 고르면 채널 할당 창이 열립니다. 할당이 끝나면 TCF마다 한 행씩 표에 추가됩니다. |
| **tif 파일 추가 (자동 인식)** | 여러 tif를 한꺼번에 고르면 파일명 키워드로 세 역할씩 묶어 표에 추가합니다. |
| **폴더에서 불러오기** | 폴더 안 tif 전부를 같은 방식으로 묶고, 하위 폴더까지 TCF를 찾아 채널 할당 창을 엽니다. 실험 날짜 폴더(예: `Tomocube/260819-1`)를 고르면 그 안의 TCF가 모두 들어옵니다. |
| **수동 추가 (tif)** | measure → reference → RI 순서로 tif를 하나씩 직접 고릅니다. |
| **채널 할당 변경** | 표에서 고른 TCF 행의 채널 할당을 다시 정합니다. 역할 칸을 더블클릭해도 됩니다. |
| **선택 삭제** | 표에서 고른 행을 지웁니다(파일은 지워지지 않음). |
| **출력 루트 폴더 지정** | 결과를 저장할 상위 폴더. 각 데이터셋은 그 안의 `<데이터셋 이름>` 폴더에 저장됩니다. |

표의 **measure / reference / RI** 칸에는 `파일 이름 › 채널`(TCF) 또는 tif 파일 이름이 보이고, 마우스를 올리면 전체 경로가 나옵니다.
출력 폴더를 지정하지 않으면 입력 파일이 있는 폴더 안의 `ParticleTracker_results/<데이터셋 이름>`에 저장됩니다.
이름과 출력 폴더 칸은 더블클릭해 직접 고칠 수 있습니다. **상태** 칸은 `완료`/`미실행`을 보여 줍니다.

#### 채널 할당 창 (TCF)
1. 위 표에 파일 안의 채널 목록(종류, 들뜸/방출 파장, 프레임 수, 크기, 촬영 간격)이 나옵니다.
2. 가운데에 채널별 첫 프레임 미리보기가 있어 어떤 형광인지 눈으로 확인할 수 있습니다.
3. 아래에서 **measure**, **reference**, **RI**에 쓸 채널을 고릅니다. 처음에는 `CH0 → measure`, `CH1 → reference`, `RI → RI`가 선택되어 있고,
   다음부터는 마지막으로 고른 할당이 기본값이 됩니다.
4. measure와 reference에 같은 채널을 고르면 [OK]가 눌리지 않습니다. RI 역할에 형광 채널을 고르는 등 흔하지 않은 할당에는 빨간 안내가 나옵니다.
5. TCF 촬영 간격이 [프레임 간격] 파라미터와 다르면 "프레임 간격을 TCF 촬영 간격으로 설정" 체크가 보입니다. 켜 둔 채 [OK]하면 파라미터가 바뀝니다.

이미 실행한 데이터셋의 할당을 바꿨다면 **처음 단계(입자 검출)부터 다시 실행**하세요.

### 3-2. 실행할 단계 고르기
아래 7단계가 순서대로 실행됩니다. 처음에는 **모두** 체크된 상태 그대로 실행하세요.

| 단계 | 내용 | 대략 비중 |
|---|---|---|
| 입자 검출 | reference에서 입자 찾기 | 짧음 |
| 정합 | reference·measure·RI 위치 맞추기 | 김 |
| 세포·영역·분열 | RI에서 세포 영역, 퍼진 세포막, 분열 세포 찾기 | 김 |
| 트래킹 | 입자를 프레임 사이로 연결 | 가장 김 |
| 측정·분류 | 밝기·비율 측정, 세포 안/밖 분류 | 짧음 |
| 그래프 | PNG 그래프 | 짧음 |
| 영상 | MP4 영상 | 보통 |

- 각 단계 결과는 `<출력 폴더>/_cache/`에 저장됩니다. 표에서 데이터셋을 고르면 아래 **캐시:** 줄에 저장된 단계가 표시됩니다.
- 앞 단계 캐시가 있으면 뒷 단계만 체크해 실행해도 됩니다. **그래프·영상만** 버튼은 그림만 다시 그릴 때 씁니다.

### 3-3. 실행
- **▶ 전체 데이터셋 실행**: 표의 모든 데이터셋을 차례로 실행
- **▶ 선택 데이터셋 실행**: 표에서 고른 것만 실행
- **■ 중지**: 지금 처리 중인 프레임까지 하고 멈춥니다. 다시 실행하면 캐시가 있는 단계 다음부터 이어 갈 수 있습니다.

진행률 막대와 아래 로그 창에서 진행 상황을 봅니다. 데이터셋 하나에 보통 5–10분(영상 포함) 걸립니다.
실행이 끝나면 상태가 `완료`로 바뀝니다.

## 4. [2. 파라미터] 탭: 값 조정과 미리보기

- 섹션(입자 검출, 정합, 세포 영역, 트래킹, 측정·분류, 특이 입자, 출력 …)을 펼쳐 값을 바꿉니다.
- **항목에 마우스를 올리면 설명**이 나옵니다.
- **저장 (YAML) / 불러오기 (YAML) / 기본값 복원** 버튼으로 설정을 관리합니다. 실험 조건별로 저장해 두면 편합니다.
- 프로그램을 닫을 때 마지막 설정이 자동 저장되어 다음에 그대로 열립니다.

### 미리보기 (오른쪽 패널)
값을 바꾸면 0.4초 뒤 자동으로 다시 계산해 **이전 값 / 현재 값** 결과를 나란히 보여 줍니다.
1. 위 목록에서 데이터셋과 프레임을 고릅니다.
2. 왼쪽 작은 영상을 클릭해 볼 위치를 정하고, 영역 크기(128/256/512 px)를 고릅니다.
3. 섹션을 펼치면 그 단계의 결과가 보입니다 (입자 윤곽과 개수, 정합 겹쳐 보기, 세포 영역, 측정 ROI 등).

처음 여는 데이터셋은 세포 영역 약 5초, 정합은 프레임당 약 9초 걸리고, 나머지는 1초 이내입니다.
분석 실행 중에는 자동 갱신이 멈춥니다([새로고침]으로 직접 갱신).

### 값을 바꾼 뒤 어디부터 다시 실행하나?
| 바꾼 섹션 | [1. 데이터·실행]에서 체크할 단계 |
|---|---|
| 입자 검출 | 전체 |
| 정합 | 정합부터 끝까지 |
| 세포 영역 / 퍼진 세포막 / 분열 세포 | 세포·영역·분열부터 끝까지 |
| 트래킹 | 트래킹 → 측정·분류 → 그래프 → 영상 |
| 측정·분류 | 측정·분류 → 그래프 → 영상 |
| 특이 입자 | [5. 특이 입자] 탭에서 분류만 다시 |
| 출력 | 그래프 / 영상 |

## 5. [3. 결과 보기] 탭

위의 **결과 폴더**에서 데이터셋 결과 폴더를 고릅니다.

### 5-1. 파일 보기
결과 폴더의 그림(PNG)·영상(MP4)·표(CSV)를 바로 미리 봅니다. 위 목록에서 `그림 / 영상 / 표(CSV)`로 거를 수 있고,
**외부 앱으로 열기**는 미리보기(Preview)·QuickTime·Excel 등 기본 앱으로 엽니다.

먼저 볼 만한 파일:
| 파일 | 내용 |
|---|---|
| `ratio_*.png` | 세포 안/밖 입자의 I(measure)/I(reference) 시간 변화 |
| `tracks_overlay.png` | 전체 영상 위 트랙 경로 |
| `qc_*.png`, `regions_*.png` | 검출·영역이 제대로 됐는지 확인용 |
| `movie_*.mp4` | 역할별(`reference_*`, `measure_*`, `RI_*`), 세포 안/밖 트랙 영상 |
| `tracks_summary_A_B_HT.csv` | 트랙별 요약(그룹: inside / outside / short / excluded_mitotic) |
| `tracks_points_A_B_HT.csv` | 트랙·프레임별 좌표, 밝기, 비율, RI (열 이름의 A = reference, B = measure, HT = RI) |

### 5-2. 트랙 탐색
- 왼쪽 트랙 표를 **그룹**과 **최소 길이**로 거릅니다. 열 제목을 누르면 정렬됩니다.
- 표의 행이나 전체 영상 위 경로를 클릭해 트랙을 고르면 오른쪽에 **밝기 그래프**(I(reference) · I(measure) · 비율 · RI, 세포 안 구간 표시)와
  **크롭**(재생, 또는 [프레임 모아보기])이 나옵니다.
- 그래프의 빨간 ×는 다른 입자와 **합쳐지거나 가려진 시점**이며, 기본으로 그 시점의 비율은 비웁니다.

### 5-3. 정답 표시 (트래킹이 맞는지 직접 확인할 때, 선택)
트래킹 정확도를 재거나 트래킹을 학습시키고 싶을 때만 쓰면 됩니다.
1. **추천 트랙 뽑기** → 확인하면 좋을 트랙 25개가 나옵니다.
2. 트랙을 고르고 **선택한 트랙으로 새 정답**.
3. 확대 화면(왼쪽 이전 프레임 / 가운데 현재 / 오른쪽 RI)에서 노란 +가 맞는지 판단합니다.
   마우스 휠 = 확대/축소, 툴바의 손 버튼 = 이동, [입자 위치로] = 가운데로.

   | 키 | 뜻 |
   |---|---|
   | Enter | 맞음 |
   | 진짜 입자 클릭 | 다른 입자를 따라갔을 때 바로잡기 |
   | M | 다른 입자와 붙음/가려짐 |
   | X | 안 보임 |
   | U | 판단 어려움 |
   | E | 여기서 끝 |
   | ← / → | 프레임 이동 |
4. 결과는 `<결과 폴더>/ground_truth.csv`에 바로 저장됩니다.
   **현재 결과 평가**로 연결 정확도를, **학습하기**로 정답에서 연결 비용을 학습해 다음 트래킹에 쓸 수 있습니다.

### 5-4. 연결 검증 (선택)
**연결 표본 만들기 (현재 결과)** → 앞뒤 프레임 크롭을 보고 **Y**(같은 입자) / **N**(다른 입자) / **U**(모름).
누락 프레임을 건너뛴 연결이 믿을 만한지 확인할 때 씁니다. 결과는 `link_checks.csv`.

## 6. [4. 통합 분석] 탭: 여러 데이터셋 합치기

1. 목록에 실행이 끝난 데이터셋 결과 폴더가 자동으로 나옵니다. 없으면 **결과 폴더 추가…**, 갱신은 **목록 새로고침**.
2. 합칠 데이터셋을 체크합니다. 폴더 이름이 데이터셋 이름으로 쓰입니다.
3. **출력 폴더**(기본: 결과 폴더 옆 `Combined`)를 확인하고 **▶ 통합 실행**.

합산 그래프와 `combined_tracks_points_A_B_HT.csv`가 만들어집니다.

---

## 7. [5. 특이 입자] 탭: 증가 후 감소하는 입자 찾기

비율 I(measure)/I(reference)가 **한 번 올라갔다가 → 급격히 또는 오래 떨어지고 → 낮게 유지**되는 입자를 찾습니다.

1. **입력**: [4. 통합 분석]의 출력 폴더(또는 CSV…로 통합 CSV, 단일 데이터셋 결과 폴더도 가능). 통합 후에는 자동으로 채워집니다.
2. **출력 폴더**: 기본 `RiseFall`.
3. 왼쪽 **판정 기준**을 필요하면 바꾸고 **▶ 특이 입자 분류 실행**. 기준을 바꿔 다시 누르면 바로 다시 분류됩니다
   (여기서 바꾼 값은 [2. 파라미터] 탭에도 반영됩니다).
4. 표 위에서 보기 범위를 고릅니다: `세포 안 / 세포 밖 / 전체`, `선별 입자만 / 후보 전체(제외 포함) / 모든 장기 트랙`.
5. **신뢰도 기준 이상만**: 결정 구간(최고점 전후)이 끝까지 같은 입자로 이어졌을 확률(`reliability`)이 기준(기본 0.5) 이상인 입자만 봅니다.

표에서 입자를 고르면 오른쪽 탭에서 확인합니다.

| 오른쪽 탭 | 내용 |
|---|---|
| 곡선 | 선택 입자의 비율 곡선과 판정 근거 |
| 전체 영상 위치 | 목록 입자들의 경로(★ = 최고점). 클릭하면 표에서 그 입자가 선택됨 |
| 크롭 프레임 | reference·measure·RI 크롭 재생 또는 모아보기 |
| 경로 교정 | 트래킹이 잘못 이어 붙인 경로를 프레임마다 고치기 (아래) |

### 경로 교정
선택한 입자의 경로를 확대 화면에서 프레임마다 확인·수정합니다.
검출(하늘색 원)을 클릭하면 그 입자로, 빈 곳을 클릭하면 그 자리를 원형 ROI로 측정합니다.
Enter = 맞음, X = 이 프레임 없음, R = 원래대로, E = 여기서 끝.
고칠 때마다 비율·밝기 그래프와 특이 입자 판정이 바로 바뀝니다. **저장**하면 `track_edits.csv`에 기록되어 통합·특이 입자 분석에 반영됩니다.

### 크롭 영상 만들기
- **선택 입자 크롭 영상 + 그래프**: 고른 입자만
- **현재 목록 전체 크롭**: 표에 보이는 입자 전부
- **결과 폴더 열기**: 만들어진 MP4·PNG를 Finder에서 엽니다.

(크롭에는 원본 데이터셋 위치 정보가 필요하므로 [4. 통합 분석]으로 통합한 결과를 입력으로 쓰세요.)

## 8. 작업 저장하기

메뉴 [파일]에서:
- **프로젝트 저장… / 프로젝트 열기…**: 데이터셋 목록과 파라미터를 함께 저장·복원
- **파라미터 저장… / 파라미터 불러오기…**: 파라미터(YAML)만

각 결과 폴더에는 사용한 입력 경로와 TCF 채널 할당(`dataset.json`)과 파라미터(`config_used.yaml`)가 함께 남아 나중에 같은 결과를 다시 만들 수 있습니다.

## 9. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| "measure / reference / RI tif 세트를 찾지 못했습니다" | 파일명에 키워드가 있는지 확인. [2. 파라미터 > 채널·시간]에서 키워드 변경 또는 [수동 추가 (tif)]. TCF는 [TCF 파일 추가] |
| "일부 TCF 건너뜀" | 할당한 채널이 그 TCF에 없음 (예: HT만 찍은 파일). 형광 채널이 있는 TCF만 고르거나 할당을 바꾸기 |
| "파일 없음" (TCF) | 외장 드라이브가 분리됨. 드라이브를 다시 연결하고 실행 |
| 결과가 이상하게 measure와 reference가 바뀐 듯함 | [채널 할당 변경]으로 할당을 확인. 채널 할당 창의 미리보기와 방출 파장으로 형광을 구분 |
| 실행 중 멈추거나 앱이 꺼짐 | 메모리 부족일 가능성. 다른 앱을 닫고 데이터셋을 하나씩 실행. 다시 실행하면 캐시 다음 단계부터 이어짐 |
| 영상이 MP4가 아니라 GIF로 저장됨 | ffmpeg를 찾지 못한 경우. 앱(.app)에는 포함되어 있으니 소스 실행 시 `pip install imageio-ffmpeg` |
| 미리보기에 "iCloud" 안내가 뜸 | Finder에서 파일을 먼저 내려받기 |
| 파라미터를 바꿨는데 결과가 그대로 | 바뀐 섹션에 해당하는 단계부터 다시 체크해 실행 (4장 표 참고) |
| 특이 입자 표가 비어 있음 | [신뢰도 기준 이상만]을 끄거나 [최소 신뢰도]를 낮춰 보기. 예전 결과는 트래킹 → 측정을 다시 실행해야 신뢰도가 계산됨 |
| 앱이 열리지 않음 ("확인할 수 없음") | [설치방법.md](설치방법.md)의 "처음 열 때 보안 경고" 참고 |
